# معاك في رحلة العلاج — نموذج أولي

منصة عربية لدعم مرضى السرطان وأسرهم. نموذج أولي (Prototype) مكتوب بـ HTML و CSS و JavaScript من غير أي مكتبات خارجية.

## التشغيل
1. فك الضغط عن الملف.
2. افتح `index.html` بدبل كليك في أي متصفح (Chrome أو Edge أو Firefox).

مفيش حاجة محتاجة تتسطب. لو بتستخدم VS Code تقدر كمان تفتح الفولدر وتشغله بإضافة **Live Server**.

> الخطوط (Aref Ruqaa و Readex Pro) بتتحمل من Google Fonts، فمحتاجة إنترنت. من غير إنترنت الموقع بيشتغل عادي بخط بديل.

## التجربة
في صفحة الدخول اختار حساب تجريبي: **مريضة** أو **مرافق** أو **أدمن**.
وتقدر تبدّل بين الأدوار الخمسة من صفحة «حسابي والخصوصية».
الحساب التجريبي للدخول: `demo@maak.eg` وكلمة السر `demo`.

البيانات بتتحفظ في المتصفح (localStorage). عشان تبدأ من الأول: «حسابي» ← «احذف الحساب».

## هيكل الملفات
```
index.html        الصفحة الرئيسية
css/style.css     التصميم كله (ألوان، خطوط، الوضع الغامق، الموبايل)
js/utils.js       أدوات مساعدة: التواريخ والأرقام العربية والأيقونات
js/data.js        البيانات: الجهات، المقالات، القاموس، البيانات التجريبية، فلتر المجتمع
js/core.js        النوافذ والتنبيهات والتنقل والصلاحيات
js/views.js       كل الشاشات والـ Features
js/app.js         شاشة الدخول وتشغيل التطبيق
```

## الـ Features
- **F1** الحسابات والخصوصية: موافقة صريحة، تحميل البيانات، حذف الحساب، ٥ أدوار.
- **F2** المواعيد: تقويم + مولّد دورات العلاج.
- **F3** الأدوية: تذكيرات، «أخدت / تخطيت»، رسم الالتزام.
- **F4** الأعراض: تسجيل من ٠ لـ ١٠، رسم التطور، تنبيه علامات الخطر، تقرير للدكتور.
- **F5** خزنة المستندات: رفع صور و PDF، التحكم في مين يشوف، روابط مشاركة مؤقتة.
- **F6** دليل الخدمات + خريطة + «مين يساعدني؟».
- **F7** المكتبة والقاموس الطبي.
- **F8** مجتمع الدعم: نشر مجهول، بلاغات، فلتر للنصايح الطبية والإعلانات ومؤشرات الخطر النفسي.
- **F9** وضع المرافق · **F10** الدعم النفسي · **F11** المساعد الذكي · **F14** بطاقة الطوارئ.
- **F13** لوحة الإدارة.
- **F12 و F15** معروضين كأفكار مستقبلية.
